## Borocito-Component
This is a component shipped with Borocito version >=x.3.x.x. And it can be managed with '`boro-get`'.  
Check [this readme](https://github.com/Borocito/Components-for-Borocito/blob/main/boro-get/README.md) to know how to implement `boro-get`, with your BorocitoCLI instances.  

## About
This plugin handles the WebSocket <-> TCP/IP connection between Borocito-CS (the new Borocito CMD/Server-Side).

> If you want some Server TCP/IP <-> Borocito TCP/IP, [broProkci](https://github.com/Borocito/Components-for-Borocito/tree/main/broProkci) is what u are looking for.

> Single Instance Package  

**This component is requiered**, on paper. But can be bypassed by using IDFTP (old communication procotol between Borocito-CLI and Borocito-CMD (through Borocito-ServerSide))  

## Usage
This component is automatically shipped with any Borocito x.3.x.x version.
